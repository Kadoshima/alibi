## Pivot #2: 写真マーケット → アリバイ素材メーカー (2026-04-10)

**Before**: 写真売買マーケットプレイス(ストックフォト的)
**After**: 「アリバイ」を作るための AI 画像合成・チケット日付編集ツール

### なぜ変えたか

写真マーケットは PIXTA / Shutterstock / Adobe Stock と真正面から競合し、
差別化が弱かった。プロジェクト名 `alibi` の本来の意味に立ち返り、
**ユーザーが自分のアリバイ素材を生成するツール** にピボット。

### 新コンセプト

> 「今日○○にいた」を証明する素材を、自分のために作れるツール。

#### ユースケース
- サプライズ準備中に「映画行ってた」と言える写真を作りたい
- 断りにくい誘いに「その日は○○で…」と言える裏付け素材が欲しい
- チケットの日付を変えて「行ったけど行けなかった」理由にしたい

#### 禁止用途
- **領収書・レシートの加工** → 脱税補助になるため完全ブロック
- **公的書類の偽造** → 犯罪
- **保険金詐欺に使える書類** → 完全ブロック

### 主要機能

| 機能 | 説明 |
|---|---|
| **顔写真登録** | 自分のセルフィーを登録。AI合成時に「自分が写っている」画像を生成 |
| **AI 画像合成** | テンプレート(映画館、レストラン等)に自分の顔を合成。Replicate API でフェイススワップ |
| **チケット日付編集** | チケット画像の日付部分だけを書き換え。OCR で検出 → テキスト上書き |
| **テンプレートライブラリ** | 場面別ベース画像(映画、旅行、飲み会、スポーツ等)を管理者が追加 |
| **禁止コンテンツフィルタ** | OCR で領収書・レシートを検出して自動ブロック |
| **クレジットシステム** | 1枚=1クレジット。都度購入 or サブスク(月N枚) |

### ビジネスモデル
- **都度課金**: 1クレジット = ¥300〜500
- **サブスク**: Free(月2枚) / Pro(月30枚, ¥980/月) / Unlimited(¥2,980/月)
- **テンプレート課金**: プレミアムテンプレートはクレジット2枚

### 技術選定の変更
- **AI推論**: Replicate API (face swap モデル)
- **OCR**: Tesseract.js (クライアント) or Google Vision API
- **コンテンツフィルタ**: OCR 結果のキーワード判定

### 残すコード
- auth (NextAuth), Stripe 決済, S3 ストレージ, 非同期ジョブキュー
- UIコンポーネント, middleware, CI/CD, Docker
- 管理ダッシュボードのシェル, 監査ログ

### 捨てるコード
- Photo / PhotoAsset / PhotoPurchase / PhotoReview / Earning モデル
- 写真カタログ・詳細・購入フロー
- アップロードフロー (プライバシー処理パイプライン)
- Studio (Canvas 編集ツール) → チケット日付編集に特化して作り直し
- pricing.ts のライセンス倍率ロジック → クレジットシステムに置き換え
- face-detection.ts → AI合成の前処理として一部流用

### 新規モデル
- `FacePhoto`: ユーザーの登録顔写真
- `Template`: シーン別ベース画像(管理者キュレーション)
- `Generation`: AI生成画像 (queued → processing → completed/failed)
- `TicketEdit`: チケット日付編集結果
- `CreditBalance`: ユーザーのクレジット残高
- `CreditTransaction`: クレジット増減履歴
